## 2. 本版修复内容

- **工具链弃用**：2026-11-17 的 `moonc 0.10.21` 将 `Buffer(size_hint=…)` / `StringBuilder(size_hint=…)` 标记为 deprecated；CI 的 `moon check --deny-warn` 因此报 10 个错误（v0.9.7 无法在新工具链上编译）。全仓库 **33 处**改为 `capacity=`（9 个 `.mbt` 文件），语义不变。
- **验证**：最新工具链下 `moon check --deny-warn --target all` exit 0；`moon test --deny-warn --target all` native **482/482**、wasm-gc/js **428/428**。
- **无公开 API / 行为变更**：仅参数名替换；`.mbti` 不变。
- **v0.9.7 关系**：v0.9.7 在其发布时（moon 0.1.20261012）CI 12/12 绿；最新工具链更新后需要本版。v0.9.7 制品保留。
