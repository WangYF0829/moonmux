## 3. 本版变更摘要

- **Windows 路径参数加固**：设备/对象命名空间（`\\.\pipe\…`、`\\.\PhysicalDriveN`、`\\?\Volume{…}`、`\\?\GLOBALROOT\…`）按能力边界 exit 2 拒绝，不再剥成 CWD 相对路径；`\\?\UNC\…` 大小写不敏感；扩展前缀只接受盘符绝对路径/UNC/`\\.\C:\`。路径规范化只作用于路径参数，`tag` 的 KEY=VALUE 文本原样保留。
- **CLI**：15 个功能子命令支持 `<cmd> --help` / `-h`（exit 0）；未知子命令仍 exit 2；`demux` / `split` 对「输出路径存在但不是目录」给出明确错误；Windows 路径长度提示边界修正为 ≥260 字符。
- **发布可复现性**：跟踪文本统一 UTF-8 无 BOM + LF；`check_package.sh --strict-repro` 在预检中启用；`RELEASING.md` 要求在 tag 的全新 checkout 上复跑 `moon package` 并比对 zip sha256。
- **安全/治理**：新增 `SECURITY.md`（私密披露渠道、SLA、已知信任边界）与 `CONTRIBUTING.md`；CI `check` job 增加 `moon doc`；`.moonignore` 变更不再被 `paths-ignore` 跳过。
- **门禁/工具**：`check_coverage.sh` 隔离历史 trace、默认总阈值 80、检测 trace 混用；`gen_sbom.sh` 脱敏构建机路径并修正 SBOM 归档导致的 worktree dirty 计数；`check_package.sh` 基线更新为 114 文件。
- **测试**：native 475 → **480**、wasm-gc/js 425 → **428**；smoke 66 → **70** 项；公开 API 文档覆盖 132 → **133**。
